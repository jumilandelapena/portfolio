Self-Healing Playwright Test Agent

An AI agent that repairs broken test locators, proves the fix on the live page, and opens a pull request for a human to review.

When a Playwright test fails because a locator no longer matches, the agent replays the passing steps in headless Chromium, shows Claude the accessibility tree, DOM and a screenshot, asks for up to three replacement locators as validated JSON, verifies each candidate live, patches only that locator with ts-morph, re-runs the test and opens a PR. Real bugs are never "healed".

  • Classifies failures first: value assertions are reported, never patched
  • Each candidate must match exactly one visible element and survive the original action
  • Mock-provider demo heals 18 locators across 10 tests with no API key
  • Strict TypeScript, Vitest unit and e2e tests, GitHub Actions CI

Chat with your PDFs (RAG with citations)

Upload PDFs, ask questions, and get streamed answers where every claim links to the exact page it came from.

Retrieval-augmented generation (RAG) done properly: hybrid vector + BM25 search fused with reciprocal rank fusion, Claude's native citations mapped back to page and quote, Server-Sent Events streaming, and a click-to-page viewer that highlights the cited passage. One docker compose up runs the whole stack.

  • Eval on a 20-question golden set: recall@8 100%, faithfulness 5.0/5, about $0.001 per question
  • Prompt caching on follow-up turns; nothing is persisted when a stream fails
  • FastAPI + PyMuPDF + Chroma back end, React + react-pdf front end
  • 60 pytest, 44 Vitest and Playwright smoke tests in CI

AI Code Review GitHub Action

A reusable GitHub Action that reviews every pull request with Claude and posts one review with inline comments and one-click fixes.

Parses the unified diff itself so it can only comment on lines that changed, measures every request with the token-counting endpoint, shares a cached system prompt across batches, validates each finding against the added lines, and never posts the same finding twice on a later push. The repository reviews its own pull requests with it.

  • Structured output with a zod schema: findings, summary, verdict and estimated cost
  • Severity table, suggestion blocks, optional failing check via fail_on
  • 71 unit tests, 13 eval cases, mock provider for CI without a key
  • Published as jumilandelapena/ai-code-review-action@v1
